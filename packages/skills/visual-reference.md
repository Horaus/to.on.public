# Visual Reference Contract

Treat uploaded images as production constraints, not loose inspiration.

Every reference must have:

- a stable name;
- a role: main character, supporting character, location, visual style, or prop;
- a factual description of what is visible;
- an explicit transformation request.

Attach relevant image files to provider jobs. Prompts must name the reference and state what must be preserved versus transformed. Never infer an unrelated identity or style when a reference is available.
